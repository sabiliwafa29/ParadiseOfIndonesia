## Data Layer Hierarchy

ParadiseOfIndonesia uses a single PostgreSQL database (Supabase). Query business tables first; avoid infra tables for analytics.

| Layer | Prefix/Tables | Purpose |
|-------|---------------|---------|
| Application | `bookings`, `travel_service_bookings` | Transactions / fact data |
| Dimensions | `tours`, `tour_packages`, `destinations`, `users` | Reference / lookup |
| Bridge | `tour_tour_package` | Many-to-many relationships |
| Infrastructure | `sessions`, `cache`, `failed_jobs` | Framework internals - avoid |
